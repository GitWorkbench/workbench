A FEW THINGS TO KNOW

Good questions.

Is Git Workbench free?+

Yes. Git Workbench is open source and distributed under the MIT license. You can inspect the code, report issues, and contribute on GitHub.

Do I need to move my repositories?+

No. Open an existing local Git repository. Git Workbench works with the system Git installation and your configured SSH keys or credential helper.

Which hosting providers can I connect?+

GitHub.com, GitLab.com, self-managed GitLab, and Bitbucket Cloud. GitHub supports browser sign-in; manual token options are available in provider settings. GitHub Enterprise and Bitbucket Data Center are not currently supported.

Is AI assistance required?+

No. AI assistance is optional. Configure a provider in Settings if you want help drafting commit messages or explaining changes. Review the generated result before using it.

How do updates work?+

The app quietly checks public GitHub releases. You choose when to download and install a supported update. Unsigned macOS builds use manual downloads. About includes a Check for updates button.
